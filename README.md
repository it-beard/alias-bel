# Аліяс па-беларуску

Вэб-версія гульні «Аліяс»: адзін гулец тлумачыць слова, каманда адгадвае.
886 беларускіх слоў, ад 1 да 5 каманд, тры ўзроўні складанасці, кірыліца або лацінка.
Працуе ў мабільным браўзеры, нічога ставіць не трэба.

**Гуляць:** https://alias.itbeard.com/

## Правілы

1. Гульцы дзеляцца на каманды (ад 1 да 5) і тлумачаць словы па чарзе.
2. Адзін гулец бярэ тэлефон і тлумачыць слова з экрана, астатнія ў камандзе адгадваюць.
3. Нельга называць аднакаранёвыя словы, перакладаць слова на іншую мову і паказваць яго жэстамі.
4. Адгадалі — **Адгадана** (ці свайп направа): +1 ачко. Не ведаеце — **Пас** (свайп налева): −1 ачко, калі ўключаны штраф.
5. Раунд доўжыцца зададзены час; пасля сігналу можна дагуляць апошняе слова.
6. Пасля раунда паказваецца спіс слоў — спрэчныя адзнакі выпраўляюцца націскам.
7. Гульня сканчаецца, калі каманда набірае мэтавы лік; круг дагульваецца, каб ва ўсіх была роўная колькасць раундаў.

## Магчымасці

- **1–5 каманд**, назвы выпадкова бяруцца са спіса і перакідваюцца кнопкай з косткай
  («Вусы Мулявіна», «Карона Вітаўта», «Мары Глобуса»…); у кожнай назвы — свой піксельны лагатып:
  вусы, карона, месяц з зоркамі ды іншыя. Знак прывязаны да назвы і мяняецца разам з ёй,
  колер вызначаецца месцам каманды ў спісе. Пры адной камандзе — сола-рэжым.
- **Тры ўзроўні складанасці** + рэжым «усе разам»:
  - лёгкі — 340 канкрэтных штодзённых слоў;
  - сярэдні — 304 паняцці, прафесіі, дзеясловы;
  - складаны — 242 тэрміны і абстракцыі.
- **Рэжым 18+** — асобны слоўнік са 108 слоў беларускай секс-лексікі паводле
  [артыкула MOST](https://mostmedia.io/2022/06/17/belaruskaja-seks-leksika/), слоўнічкаў «Нашай Нівы», PALATNO
  і Радыё Свабода: ад «заляцацца» да «шмаравідла».
  Стаіць апошнім у перамыкачы ўзроўняў, уключаецца пасля пацвярджэння ўзросту і ў «усе разам» не трапляе.
- **Кірыліца або лацінка**: словы, назвы камандаў, увесь інтэрфейс і загаловак укладкі транслітаруюцца ў беларускую лацінку
  (Biełaruś, Mahiloŭ, hulnia) паводле класічных правілаў.
- **Светлая і цёмная тэмы** (або аўта): стрыманая палітра «лён і чырвань», ромб як знак гульні.
- Галоўны экран — толькі каманды, узровень слоў і раунд; рэдкія налады (алфавіт, тэма, штраф,
  апошняе слова, гук, вібрацыя) схаваныя ў шторку за іконкай у шапцы.
- Налады раунда: час (30/45/60/90 с), мэтавы лік (20/30/50/75), штраф за пас, правіла апошняга слова.
- Зроблена пад тэлефон: адлік 3‑2‑1 перад раундам, свайп карткі з візуальным адгукам,
  вялікія кнопкі ў зоне вялікага пальца, абарона ад падвойнага націску, ландшафтная раскладка,
  пацверджанне перад завяршэннем гульні, гук і вібрацыя, экран не гасне падчас раунда.
- З ноўтбука: стрэлкі ← → адказваюць, прабел ставіць паўзу.
- Стан гульні захоўваецца ў браўзеры — можна закрыць укладку і вярнуцца, а з наладаў
  працягнуць незавершаную партыю.
- Пасля перазагрузкі адказы і вынікі раунда захоўваюцца. Актыўны раунд аднаўляецца на паўзе;
  калі час ужо выйшаў — прымяняецца правіла апошняга слова. Перад зменай колькасці каманд
  або пачаткам новай партыі гульня папярэджвае пра скід рахунку.
- Дадаецца на хатні экран як асобная праграма (PWA-маніфест).

## Распрацоўка

```bash
npm install
npm run dev            # лакальны сервер
npm test               # тэсты (vitest + testing-library)
npm run test:coverage  # тэсты з пакрыццём
npm run lint           # oxlint
npm run build          # зборка ў dist/
npm run deploy         # ручная публікацыя на GitHub Pages (галіна gh-pages)
```

### Аўтаматызацыя (GitHub Actions)

- **Deploy** ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)) — пры кожным пушы ў `main`
  правярае лінтар і тэсты, збірае праект і публікуе `dist/` у галіну `gh-pages`. Калі праверкі
  не прайшлі, сайт не абнаўляецца. Можна запусціць і ўручную з укладкі Actions.
- **CI** ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)) — тыя ж праверкі для кожнага pull request,
  у тым ліку ад Dependabot.
- **Dependabot** ([`.github/dependabot.yml`](.github/dependabot.yml)) — штопанядзелка правярае абнаўленні
  npm-пакетаў і GitHub Actions і адкрывае pull request'ы: React асобнай групай, астатнія
  дробныя абнаўленні адным PR, мажорныя — паасобку.

Стэк: React 19 + Vite, звычайны JavaScript і CSS, без знешніх бібліятэк у рантайме.
Шрыфты (Manrope, Unbounded) убудаваныя ў зборку праз fontsource.

### Структура

```
src/
  data/words.js        слоўнікі па ўзроўнях складанасці
  game/                стан гульні (reducer), калода, захаванне, гук, скланенне лічэбнікаў
  i18n/                транслітарацыя ў лацінку і кантэкст алфавіту
  ornament/            піксельныя лагатыпы каманд, матывы арнаменту і SVG-геаметрыя
  hooks/               таймер, свайп, клавіятура, wake lock
  components/          экраны: налады, гатоўнасць, гульня, вынік, фінал; знакі, шторкі
  theme.js             тэма (data-theme, theme-color) і мова дакумента
  test/                наладка vitest, дапаможнікі для таймераў
```

Тэсты ляжаць побач з кодам (`*.test.js(x)`): reducer і калода, транслітарацыя (у тым ліку
ўвесь слоўнік), слоўнікі (колькасць, унікальнасць, алфавіт), арнаменты, хукі, кожны экран,
поўная партыя праз `App` і снапшоты экранаў у абодвух алфавітах.

Словы — у файле [`src/data/words.js`](src/data/words.js), правапіс афіцыйны. Дадаць сваё слова
можна ў адпаведны масіў: `EASY`, `MEDIUM` ці `HARD`. Новы лагатып каманды — матрыца 15×15 з «X» і «.»
у [`src/ornament/teamLogos.js`](src/ornament/teamLogos.js). Назва і ключ лагатыпа дадаюцца ў
`TEAM_MOTIFS` у [`src/game/constants.js`](src/game/constants.js); спіс выпадковых назваў будуецца з яго.
